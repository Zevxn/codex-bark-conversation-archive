# 本地对话查看面板

查看面板用于读取本项目生成的月度 JSON 归档，并按项目、日期和会话浏览完整问答。所有解析、搜索和渲染都在浏览器本地完成。

## 启动

### 一键启动（Windows）

直接双击项目根目录中的：

```text
启动对话面板.cmd
```

启动文件会自动查找 `python` 或 Windows `py` 启动器，运行本地服务并打开默认浏览器。保持命令窗口运行即可继续使用看板；关闭窗口或按 `Ctrl+C` 可以停止服务。

### 命令行启动

在项目根目录执行：

```powershell
python conversation_viewer.py
```

默认地址为：

```text
http://127.0.0.1:8765/
```

程序会尝试自动打开浏览器。只启动服务而不打开浏览器：

```powershell
python conversation_viewer.py --no-browser
```

端口被占用时，可以指定其他端口：

```powershell
python conversation_viewer.py --port 8766
```

## 读取记录

推荐使用最新版 Chrome 或 Edge。

### 根据本地配置自动加载

服务启动时会读取项目根目录的：

```text
config.local.json
```

如果其中的 `history_dir` 指向有效目录，并且目录第一层包含 `Codex对话记录_YYYY-MM.json`，页面会自动读取并展示该目录中的全部月度记录和对话索引。

以下情况不会自动打开任何数据源，页面会停留在手动选择界面：

- `config.local.json` 不存在或不是有效 JSON；
- `history_dir` 没有配置；
- 配置的目录不存在或无法访问；
- 目录中没有月度对话记录文件。

自动加载失败时不会改用最近目录。用户仍可通过“选择记录目录”“选择 JSON”或“最近的数据源”手动载入。

### 目录模式

点击“选择记录目录”，选择包含以下文件的归档目录：

```text
Codex对话记录_2026-07.json
Codex对话记录_2026-08.json
Codex对话索引.json
```

页面只读取目录第一层中的月度记录和对话索引，不会读取 `.prompt_cache`、`.locks` 或其他文件。

支持 File System Access API 的浏览器会把目录句柄保存在 IndexedDB 中，并列在“最近的数据源”中。未使用配置自动加载时，用户可以从最近列表主动切换到这些目录；浏览器要求重新确认权限时会显示授权提示。

如果归档目录被移动，可以重新选择新目录。最近数据源下拉框用于在多个归档目录之间切换，也可以移除已经失效的旧目录。

### 文件模式

点击“选择 JSON”，可以一次选择一个或多个月度记录文件，也可以同时选择 `Codex对话索引.json`。索引用于补全旧记录中缺失的对话标题。

## 面板行为

- 日历热度按每天的问答轮数计算。
- 没有对话的日期不可点击；再次点击当前选中的日期会取消日期筛选，展示当前项目的全部历史记录。
- 日期优先使用 `prompt_time`，缺失时使用 `response_time`。
- 点击日期后，记录先按项目分组，再按 `session_id` 聚合为对话。
- 对话默认保持收起；可以展开单条对话，或使用右上角按钮统一展开和收起。
- 同一 `record_id` 出现在多个文件中时会自动去重。
- 项目优先使用规范化后的 `cwd` 识别，避免仅因项目名称大小写不同而重复分类。
- 选择左侧项目后，统计、日历和当日记录都会切换到该项目。
- 搜索范围包括项目、工作目录、对话标题、问题、回答和模型。
- Markdown 支持表格、任务列表、代码高亮、KaTeX 公式和 Mermaid 图表。

## 隐私与安全

- 本地服务器仅监听 `127.0.0.1`，除非启动时主动指定其他地址。
- 自动加载时，本地 Python 服务会把配置目录中的对话内容传给同一台电脑上的页面；内容不会提交到第三方接口。
- 前端依赖已经保存在 `viewer/vendor`，运行时不访问 CDN。
- 内容安全策略只允许页面请求同源的本地服务，并禁止跨站图片和第三方网络请求。
- Markdown 中的原始 HTML 会经过白名单清洗，脚本、表单、内嵌页面和事件属性不会执行。

## 浏览器限制

目录句柄的长期记忆依赖 File System Access API。Chrome 和 Edge 支持较完整；不支持该接口的浏览器仍可通过备用文件选择器读取目录，但浏览器重启后需要重新选择。
